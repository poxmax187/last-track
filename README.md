# Последний трек — Android-приложение

Это оболочка (WebView), внутри которой работает игра: `app/src/main/assets/index.html`.
Игра полностью автономна, интернет не нужен. Сохранения хранятся на устройстве.

## Как получить APK

### Способ 1. Через GitHub (без Android Studio, всё в браузере)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий (Private подойдёт).
2. Загрузите в него всё содержимое этой папки (кнопка «Add file → Upload files»; папку `.github` тоже, она скрытая — перетащите её вместе с остальными файлами).
3. Откройте вкладку **Actions → Build APK → Run workflow**. Через 3–5 минут появится готовая сборка.
4. Откройте завершённый запуск и скачайте артефакт **last-track-apk** (внутри `app-debug.apk`).
5. Перенесите APK на телефон и установите (Android попросит разрешить установку из неизвестных источников).

### Способ 2. Android Studio
1. Установите Android Studio (бесплатно).
2. `File → Open` и выберите эту папку, дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`. Файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 3. Онлайн-конвертер сайта в APK
Если не хочется ничего устанавливать: возьмите из папки `app/src/main/assets/` файл `index.html`, положите его в ZIP (файл в корне архива) и загрузите на любой сервис вида «HTML to APK / website to app». Качество и рекламу в таких сервисах я не контролирую.

## Что внутри
- `app/src/main/assets/index.html` — игра (обновляйте этот файл, если игра меняется, и пересобирайте APK).
- `MainActivity.java` — WebView; ссылка «Связаться с автором» открывает почтовое приложение.
- `app/src/main/res/mipmap-*/ic_launcher.png` — иконка.
- `.github/workflows/build-apk.yml` — автосборка на GitHub.

## Публикация в Google Play
Для магазина нужны подписанный релиз (AAB) и собственный ключ. Отладочный APK годится для установки себе и друзьям.
